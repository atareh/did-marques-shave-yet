# Did Marques Shave Yet?

A fan-parody site that tracks the Cybercab head-shaving bet. It isn't affiliated with Marques Brownlee or Tesla.

It's one static page: `index.html` plus the files in `assets/`. There is no build step. Vercel serves the folder as-is.

## Sound

The clipper buzz (`assets/clipper-razor.mp3`) is a 2.0 s seamless loop cut at the 14 s mark from "Electric Razor Sound Effect.mp3", which the owner supplied. The full original and a quieter variant are kept outside the repo in `did-marques-shave-yet-originals/`.
